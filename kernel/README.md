# Admission kernel boundary

No authoritative kernel is implemented in this scaffold. The executable
prototype lives in `reference/` and produces bounded observations.

Goose is the designated language for future kernel work. Introducing that
kernel requires naming the boundary and implementation, satisfying the
promotion conditions in `ARCHITECTURE.md`, and updating authority declarations
in the same reviewed change. This directory documents the boundary and contains
no placeholder executable that could appear to validate Lean theorems.
